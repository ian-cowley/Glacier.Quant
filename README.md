# Glacier.Quant

Standalone SIMD and GPU tensor quantization engine for .NET 10, featuring streaming GGUF and Safetensors I/O, `Q4_K_M`, `Q8_0`, `FP8`, and 1-bit binary quantization kernels, and AWQ/GPTQ/`imatrix` post-training quantization (PTQ) calibration.

## Installation

```bash
dotnet add package Glacier.Quant
```
